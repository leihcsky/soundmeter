    Microphone Troubleshooting

    No sound detected ▼
    • Confirm the correct input in the device menu above (headset vs laptop mic).
    • Unmute the mic in Windows / macOS sound settings and raise input volume.
    • On Bluetooth headsets, set the headset as the default input—not only as output.
    • Close Zoom, Teams, or other apps that may lock the microphone.
    Permission denied ▼
    • Chrome / Edge: click the lock or tune icon in the address bar → Site settings → Microphone → Allow, then reload.
    • Safari (Mac/iOS): Safari → Settings for This Website → Microphone → Allow.
    • Android Chrome: site permissions → Microphone → Allow.
    • OS privacy: Windows Settings → Privacy → Microphone; macOS System Settings → Privacy & Security → Microphone.
    Input too low or distorted ▼
    • Move closer (about a hand’s width for headset mics; 15–30 cm for desk mics).
    • Raise system input gain carefully—too high causes clipping/distortion.
    • Disable conflicting “enhancements” or exclusive-mode apps if the level jumps wildly.
    • Playback sounds fine but meetings don’t? Check the meeting app’s own mic picker separately.

    How to Test Your Microphone Online

    1. Start and allow access

    Press Start Microphone Test and approve the browser prompt. This online microphone test never asks for the mic until you click.

    2. Watch the level and waveform

    Speak normally. If the bar moves and you see “Microphone is receiving sound,” your selected input is working for the browser—a quick mic check before you join a call.

    3. Switch devices if needed

    Use the input list to compare laptop, USB, and headset mics. Stop other apps if a device is busy. For placement tips, see how to measure more accurately and smartphone mic limits.

    4. Optional deeper checks

    After the meter shows your mic is receiving sound, use Check Voice Quality for a short quiet + speaking check with suggested fixes. You can also record up to 15 seconds and play it back. Then test speakers with our Speaker Test or measure room noise with the Sound Meter.

    Frequently Asked Questions

    Is this mic test free?

    Yes. This free mic test runs in your browser with no install or account. Allow microphone access when prompted.

    Do you upload my voice?

    No. Live levels and any recording stay in your browser memory for this session. Stopping or leaving the page releases the mic and recording data.

    Why does the level show a percent, not dB?

    This online microphone test checks whether the mic receives sound. The bar is a relative digital input meter, not a calibrated SPL reading. Use our online sound meter for environmental noise estimates.

    Will this prove Zoom or Teams can hear me?

    If this page detects your voice, the browser path works. Meeting apps still need the same device selected inside their own settings. Use this as a quick “test my mic” check before you join.

    Can I test speakers here too?

    Use the Speaker Test for left/right channels and tones, or the Tone Generator for custom frequencies.

    What does Check Voice Quality do?

    It is an optional ~10–15 second guided check: 3 seconds quiet, then about 5 seconds of normal speaking. You get plain-language results about speaking level, background input, and possible clipping—plus suggested fixes you can verify with Test Again. It measures browser digital input (not room dB SPL) and is not a lab or medical certificate.
